# Praktikum 4 - CSS Layout

## Deskripsi
Praktikum ini membahas penggunaan CSS Layout untuk mengatur posisi dan tampilan elemen pada halaman website. Praktikum dilakukan menggunakan HTML dan CSS dengan membuat layout website sederhana.

## Tujuan Praktikum
1. Memahami penggunaan elemen box pada HTML.
2. Memahami penggunaan properti CSS float dan clear.
3. Membuat layout website menggunakan HTML dan CSS.
4. Mengatur posisi bagian header, navigasi, konten utama, sidebar, dan footer.
5. Membuat beberapa halaman website yang saling terhubung.

## Struktur Folder
- `lab4_box.html` : halaman untuk latihan box element, float, dan clear.
- `lab4_layout/home.html` : halaman utama website.
- `lab4_layout/artikel.html` : halaman artikel.
- `lab4_layout/about.html` : halaman tentang website.
- `lab4_layout/kontak.html` : halaman kontak.
- `lab4_layout/style.css` : file untuk mengatur tampilan website.
- `lab4_layout/images/` : folder untuk menyimpan gambar.

## Hasil Praktikum
Website dibuat dengan beberapa bagian, yaitu header, navigasi, hero, konten utama, sidebar, dan footer. CSS digunakan untuk mengatur tata letak, ukuran, warna, serta posisi elemen. Menu navigasi digunakan untuk berpindah dari satu halaman ke halaman lainnya.

## Kesimpulan
Melalui praktikum ini, saya belajar menggunakan CSS untuk mengatur layout website. Saya juga belajar menghubungkan file HTML dengan CSS eksternal, menggunakan float dan clear, serta membuat beberapa halaman website yang terhubung melalui menu navigasi.
